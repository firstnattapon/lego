1 เส้นทางการทำงานใน 1 รอบ (Tick Lifecycle)
Phase 1 ⏰

ปลุก & ตรวจงานเก่า

Cloud Scheduler ยิงกระตุ้นทุกนาที พร้อมเคลียร์งานค้างก่อนเริ่มอะไรใหม่

  • รับสัญญาณจาก Cloud Scheduler (OIDC Auth)
  • ตรวจสอบ Order เก่าที่ยังไม่จบ (Recovery)
  • ถาม Webull ด้วย Order ID เดิม ไม่มียิงซ้ำ
entrypoint: lego_tick()
Phase 2 📊

ตรวจเวลา & ดึงราคา

เช็คความพร้อมของตลาด NYSE และอ่านพอร์ตโฟลิโอล่าสุด

  • เช็ควันหยุด, เวลาเปิด-ปิดตลาด, DST
  • หา Slot ID (เช่น 2026-09-07:15)
  • ดึงราคาล่าสุด Pₙ และจำนวนหุ้นจาก Webull
market_clock.py + webull_io.py
Phase 3 🧬

ตัดสินใจ & บันทึกโมเดล

ประเมิน DNA และคณิตศาสตร์ Rebalance พร้อมลงบันทึก 17 คอลัมน์

  • DNA = 0 ➔ PASS (พักผ่อนทันที)
  • DNA = 1 ➔ คำนวณ |Fix_c - Value| vs DIFF
  • บันทึกแถวใหม่ลง Firebase RTDB (Idempotent)
dna_engine.py + lego_one_row.py
Phase 4 🚀

ส่งคำสั่ง & คิดกำไร FIFO

ผ่านด่านตรวจความปลอดภัย ส่งออเดอร์ และบันทึกกำไรจริงเมื่อ Match

  • เช็ค Safety: Active? Mode? Preview ผ่านไหม?
  • ส่งคำสั่งไป Webull (Place Order)
  • เมื่อ Fill จริง ➔ คำนวณ FIFO Realized Ledger v3
execution_service.py + ledger_v2.py
2 ลองทดลองปรับตัวเลข (Interactive Rebalancing Engine)
🕹️ กล่องทดลองการตัดสินใจแบบ Real-Time
ปรับสไลเดอร์เพื่อดูการคิดคำนวณของระบบทันที
ราคาหุ้นปัจจุบัน (Pₙ) $6.50
จำนวนหุ้นที่ถืออยู่ (Holdings) 200 หุ้น
เป้าหมายมูลค่าพอร์ต (Fix_c) $1,500.00
เกณฑ์ส่วนต่างขั้นต่ำ (DIFF Threshold) $25.00
สัญญาณ DNA ของสล็อตนี้
ผลการประเมินรอบนี้ (Decision Status)
READY_BUY
มูลค่าพอร์ตปัจจุบัน (Holdings × Pₙ) $1,300.00
ส่วนต่างจากเป้า (Gap = Fix_c - มูลค่า) +$200.00
จำนวนหุ้นที่ต้องสั่งซื้อ/ขาย 30.769 หุ้น
สถานะการส่งคำสั่ง ส่งคำสั่งซื้อ (BUY)
มูลค่าหุ้นในมือ ($1,300.00) ต่ำกว่าเป้าหมาย ($1,500.00) อยู่ $200.00 ซึ่งมากกว่าเกณฑ์ DIFF ($25.00) ➔ ระบบจึงสั่ง ซื้อเพิ่ม 30.769 หุ้น ที่ราคา $6.50

LEGO PRINCIPAL v2 แยกตัวเลขทางทฤษฎีออกจากเงินจริงอย่างเด็ดขาดเพื่อความถูกต้อง 100%

จุดเปรียบเทียบ 📘 บัญชีโมเดล (Model Ledger) 🏦 บัญชีจริงโบรกเกอร์ (Broker Cashflow)
เวลาที่บันทึก บันทึกทันทีเมื่อคำนวณจบในสล็อต (READY_BUY / SELL) บันทึกเฉพาะเมื่อโบรกเกอร์จับคู่ Match สำเร็จจริง (Fill)
ตัวแปรหลัก Rₙ (เกณฑ์อ้างอิง), ΔAₙ, Aₙ, Eₙ (ส่วนเกินสะสม) Executed Quantity, Executed Price (VWAP), Fees
ผลกรณีเน็ตหลุด ไม่ย้อนคืนแถวโมเดล (Model ไม่ Rollback) ตรวจสอบสถานะจริง หากยังไม่แมตช์จะไม่คิดกำไร
กำไรที่แท้จริง (Realized PnL) เป็นเพียงตัวเลขทางสถิติของโมเดล คำนวณจากตั๋วซื้อขายจริงด้วยระบบ FIFO Bounded V3
? คำถามที่พบบ่อย (Quick FAQs)
❓ ทำไมต้องมี DNA Signal (0 และ 1)?
DNA เปรียบเสมือนสวิตช์จังหวะเวลาที่ผ่านการ Backtest มาแล้ว หากรอบนั้น DNA เป็น 0 ระบบจะพัก (PASS) ทันที ช่วยหลีกเลี่ยงการเทรดในสภาวะตลาดที่ไม่เป็นใจ
❓ ถ้าเน็ตหลุดระหว่างส่งคำสั่งจะเกิดอะไรขึ้น?
ระบบจะเปลี่ยนเป็นสถานะ SUBMIT_UNKNOWN และจะไม่มีการส่งออเดอร์ใหม่ซ้ำเด็ดขาด แต่จะนำ Client Order ID เดิมไปไล่เช็คกับโบรกเกอร์ในรอบถัดไปจนทราบผลชัดเจน
❓ โหมด Observe กับ Trade ต่างกันอย่างไร?
Observe จะรันทุกอย่างเหมือนจริง คำนวณโมเดล บันทึกตาราง แต่จะ "ไม่กดส่งเงินจริง" เหมาะสำหรับทดสอบความนิ่ง ส่วน Trade จะเปิดให้ส่งคำสั่งซื้อขายจริง
❓ ทำไมหนึ่งสล็อตจึงมีได้แค่ 1 แถว? (One Slot, One Row)
เพื่อความแน่นอน (Deterministic) หาก Scheduler ส่งสัญญาณซ้ำในนาทีเดิม ระบบจะตอบ SLOT_CONSUMED และไม่คำนวณเบิ้ม ป้องกันการเทรดซ้ำซ้อน 100%
