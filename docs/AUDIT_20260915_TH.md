## ข้อสรุป

**ยังไม่ผ่านเกณฑ์เปิดเงินจริง (NO-GO)**

หลักฐาน UAT แสดงการตัดสินใจต่อเนื่อง การกู้คืนคำสั่ง และการบันทึก fill/fee ที่สอดคล้องกัน

## 4. การตั้งค่า cloud ที่ตรวจได้และยังตรวจไม่ได้

revision concurrency=1, revision max instances=1, CPU=0.3333, memory=512Mi;

rules ใน source เปิด anonymous read สำหรับ rows/state/order_audit/warnings และปิด client write

## 6. เกณฑ์ปิดงานก่อนเปิดเงินจริง

ทำตามลำดับนี้และเก็บหลักฐานของ candidate เดียวกัน:

1. **ยืนยัน release:** build source manifest + immutable image digest + revision + dependency list
   ต้องตรงผลทดสอบ; deploy candidate ที่แก้แล้วลง UAT และตรวจ behavior หลัง deploy
2. **ยืนยัน broker contract:** บัญชีและ endpoint ที่จะใช้ต้องผ่าน account visibility, position,
   fresh quote, profile, buying power และ open-orders หลายหน้า
   ทดสอบคำสั่งที่ได้รับอนุมัติผ่าน preview → Place → terminal quantity/VWAP/actual fee → holdings/cash;
   ต้องครอบคลุม SELL, partial fill, cancel/reject และ query หลังผล Place ไม่ชัดเจน
3. **ทดสอบความต่อเนื่อง:** cold start, timeout, process crash หลัง fence/หลัง Place, late fee,
   pause/resume และ restart ต้องไม่เกิด Place ซ้ำ; unresolved order ต้องกั้นคำสั่งใหม่ได้
   แนะนำ soak อย่างน้อย 3 วันตลาดเต็ม รวมเปิด/ปิดตลาด โดยกำหนด latency/backlog/quota limits ก่อนเริ่ม
4. **ยืนยันการปฏิบัติงาน:** ตรวจ IAM/OIDC, deployed rules และการเข้าถึงข้อมูล;
   ทดลอง alert ERROR/FEE_OVERDUE/MANUAL_RECONCILIATION_REQUIRED/DNA_LOW/DNA_EXHAUSTED,
   missing tick ในช่วงที่ควรรัน และ restore จาก backup พร้อมผู้รับผิดชอบ
5. **อนุมัติขอบเขตเงินจริง:** ระบุ environment, บัญชีผ่าน secret reference, symbol,
   ทิศทาง/จำนวน/วงเงินของการทดสอบจริงและขีดจำกัดที่ยอมรับได้; จัดรอบ DNA renewal ก่อนหมดอายุ
