## ต้นทุน: fee เทียบกับสิ่งที่กลยุทธ์ทำได้ (แบบจำลอง ไม่ใช่คำพยากรณ์)

กลยุทธ์ถือหุ้นมูลค่า ≈ FIX_C ดอลลาร์คงที่ ซื้อ/ขายทั้ง gap เมื่อ |V − FIX_C| > DIFF ⇒ **ผลก่อน fee เท่ากับการถือ FIX_C ดอลลาร์ของหุ้น** (ในแบบจำลองต่างกันไม่เกินสัญญาณรบกวน) — ไม่มี alpha เพิ่มเมื่อราคาเป็น random walk;
alpha มีได้เมื่อราคากลับเข้าหาที่เดิมเท่านั้น และ**ทุก order จ่าย fee ไม่ว่าราคาทำอะไร** (`release_evidence/20261010-pr/fee-drag-sim.py`, numpy อย่างเดียว, seed คงที่, ไม่มี slippage/bid-ask/ภาษี, 1,500 เส้นทาง; ผลลัพธ์เต็มของ σ = 15% และ 35% อยู่ข้างสคริปต์ใน `fee-drag-sim-sigma15.txt` / `fee-drag-sim-sigma35.txt`)
ความผันผวนที่วัดจาก 19 แถวของ session นี้ = 0.207% ต่อ slot ≈ **17%/ปี** (audit 6 ต.ค. วัดได้ 0.189% ต่อ slot ≈ 15%) — จึงแสดงที่ σ = 15% เป็นหลัก และ σ = 35% เทียบ

USD ต่อปี ต่อ FIX_C 10,000, DIFF 25 (ค่าที่ตั้ง) — ค่าในวงเล็บ = standard error:

| โลกของราคา (σ = 15%) | ก่อน fee | fee 0.15% | fee 0.50% | fee 1.07% (UAT) |
|---|---|---|---|---|
| median-flat (ราคาไม่มี drift ใน log; ดีที่สุดสำหรับกลยุทธ์) | +83.8 (39) | −4.7 | −211.2 | **−547.4** |
| martingale (ถือหุ้นแล้วไม่ได้อะไร) | −28.7 (39) | −117.2 | −323.7 | −659.9 |

σ = 35%: median-flat ก่อน fee +545.4, fee 0.15% → +249.9, 0.50% → −439.5, 1.07% → −1,562.3; martingale ก่อน fee −67.1, 0.15% → −362.6, 0.50% → −1,052.0, 1.07% → −2,174.7 (orders ≈ 3,745/ปี ที่ DIFF 25; ที่ σ = 15% ≈ 1,649/ปี)
DIFF กว้างขึ้นลดจำนวน order และ fee (σ = 15%, fee 0.15%: DIFF 100 → +53.6 / −59.0, DIFF 300 → +72.5 / −39.6 ในโลก median-flat / martingale) แต่**ไม่เปลี่ยนว่ากลยุทธ์ไม่มี edge ในตัว**

ข้อสรุปที่ตรงไปตรงมา:
- ที่ fee UAT (1.07%) กลยุทธ์ขาดทุนเกือบทุกกรณีแม้ในโลกที่ดีที่สุด — ตรงกับที่วัดจริง (realized −1.34 USD / 5 fills; `trace_audit`: order มัธยฐาน 32.66 USD vs break-even 214.27 USD, ≈ 4.4% ของ FIX_C ต่อปีถ้า session นี้เป็นตัวแทน — **ตัวเลขนี้ extrapolate จาก 1 session ซึ่งเป็นวันเงียบ ไม่ใช่อัตรา**)
- ที่ fee PROD ที่สมมติ 0.15% และ DIFF 25 ผลสุทธิ ≈ 0 ในโลกที่ดีที่สุด และติดลบในโลก random walk — **เงินจริงไม่มีหลักฐานว่าคุ้ม** และ UAT พิสูจน์ไม่ได้ (fee PROD ต้องวัดด้วย Preview Order; ความได้เปรียบต้องมาจากสมมติฐานเรื่องราคาที่เจ้าของบัญชีเชื่อ ไม่ใช่จากโค้ด)
- สูตร "DIFF ≥ 2 × fee × FIX_C" ที่ใช้เป็นเกณฑ์กรณีดีที่สุดต่อ order (ราคากลับที่เดิมเต็มรอบ) **เป็นเงื่อนไขจำเป็นของ order หนึ่งใบเท่านั้น ไม่ใช่การรับรองกำไร และไม่ใช่ gate** (แบบจำลองแสดงว่ามันทั้ง BLOCK ผิดที่ fee ต่ำ และให้ความมั่นใจเกินจริงในโลก random walk)

- ผมรัน broker, Firebase, Cloud Run และ Cloud Monitoring จริงไม่ได้ในสภาพแวดล้อมนี้ และ `developer.webull.co.th` เข้าไม่ได้ — ผลทั้งหมดมาจากหลักฐานที่แนบ, เทสต์ในเครื่อง และ contract ที่ repo เก็บ

- PR นี้เปลี่ยน candidate hash: revision ที่รันอยู่ (`00043-tux`) ยังทำงานตามเดิมจนกว่าจะ deploy release ใหม่
